# Release 0.8.1

## Total Control V7.0 PERF

An integrated Windows workstation for camera observation, photon counting, PYNQ gating and syringe-pump control.

- Prebuilt x64 workstation and x86 CH297 bridge.
- C# source, Visual Studio solution, build scripts and English user interface.
- Matching Python PYNQ PERF service with regression tests for output cleanup and sequence tracking.
- English build and operation guide in PDF, Word and Markdown.
- Editable hardware BOM, wiring instructions and engineering figures.
- One selected droplet microscopy MP4, directly accessible from the project README.

The Windows package includes all project source and resources. The source archive provides the same project without compiled executables. Documentation and examples have been consolidated into this focused release.

Install .NET Framework 4.8+ and the instrument vendors' camera and CH297 components as described in [Windows Setup](Software/PC_Control/TotalControl_V7_0/WINDOWS_RUNTIME.md).
