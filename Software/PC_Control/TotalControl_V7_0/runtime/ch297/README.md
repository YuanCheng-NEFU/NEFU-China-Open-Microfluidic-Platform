# CH297 Runtime

The Windows package places the compiled x86 bridge in this directory. Install the vendor's 32-bit PMTCount.dll, its required dependencies and the matching instrument para.ini here under the vendor's terms.

Keep vendor configuration keys and calibration unchanged. Complete x86 COM registration for this exact installation path. Do not move the directory after registration without updating the installation.

See [Windows Runtime](../../WINDOWS_RUNTIME.md).
