# Camera SDK

Install the complete x64 OsCam SDK and camera driver. The application searches NEFU_OSCAM_DIR, the standard OsCam installation folders, then its application directory.

This folder is an optional staging location only. Set NEFU_OSCAM_DIR to its absolute path when installing the SDK here. The public project does not bundle vendor DLLs.

See [Windows Runtime](../../WINDOWS_RUNTIME.md).
