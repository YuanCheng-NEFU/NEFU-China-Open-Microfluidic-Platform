# PYNQ-Z2 | V7.0 PERF

The board-side companion to **Total Control V7.0 PERF** provides per-sample acknowledgments, threshold gating, sequence accounting and local processing-time statistics.

## Deploy

Use a PYNQ-Z2 image that provides `pynq`, `BaseOverlay("base.bit")` and Python 3.7 or later. Upload `pynq_v6_perf_server.py` through the board's Jupyter interface to:

```text
/home/xilinx/jupyter_notebooks/NEFU_iDEC/
```

Keep high voltage disabled during deployment. In Total Control, request **Force LOW** and confirm the output with a scope before stopping any existing server. Only one process may own TCP port 5000. If the older R2 system service is installed, stop it with `sudo systemctl stop nefu-idec-gate.service`; do not launch both servers.

Start the V7 server from a board terminal:

```bash
cd /home/xilinx/jupyter_notebooks/NEFU_iDEC
python3 pynq_v6_perf_server.py
```

The terminal prints `Listening on 0.0.0.0:5000`. Enter the board's IP address and port `5000` in Total Control. Keep the board on a trusted laboratory network; this TCP service has no authentication or encryption. Stop with **Ctrl+C**. SIGTERM also runs the output cleanup; do not use forced termination.

## Connect

| Signal | Connector | Function |
| --- | --- | --- |
| GATE | PMOD B Pin 1, index 0 | 0 / 3.3 V gate output |
| RX_MARK | PMOD B Pin 2, index 1 | Sample-processing timing marker |
| GND | PMOD B Pin 5 or Pin 11 | Low-voltage signal reference |
| LED0 | On-board | Mirrors the requested GATE state |

Connect scope CH1 to RX_MARK and CH2 to GATE. Observe the rising-edge interval for a sample that changes GATE from LOW to HIGH. RX_MARK rises after JSON decoding and parameter validation, so this scope interval is not the full network or acquisition latency. Use the correct ground reference and keep PMOD wiring separate from high-voltage electrodes.

## Operate

| Command | Result |
| --- | --- |
| `hello` | Connection handshake |
| `set_params` | Apply threshold and hysteresis |
| `auto` | Arm threshold gating, initially LOW |
| `force_low` | Disarm and drive GATE LOW |
| `pulse` | Manual pulse, 1-5000 ms |
| `heartbeat` | Refresh client contact time |
| `reset_stats` | Reset sequence and latency counters |
| `get_stats` | Return counters in the next status response |

The default threshold is **15000 counts**, with **100 counts** of hysteresis. In AUTO, GATE rises at `count >= threshold` and falls at `count <= threshold - hysteresis`. Set the threshold for the selected CH297 acquisition window and experiment.

Startup, connection reset and disconnect drive GATE LOW. Invalid samples drive GATE LOW. AUTO applies a **1 s** valid-data timeout; client inactivity applies a **3 s** timeout and disarms the gate. Malformed JSON disarms the gate immediately. A manual pulse returns LOW at its configured end; invalid samples, Force LOW, disconnect or client timeout can end it earlier.

## Protocol and Records

UTF-8 JSON Lines are exchanged over TCP:

- Samples: `PYNQ_PERF_V1`, with `seq`, `count`, `valid`, `status`, `threshold` and `hysteresis`.
- Per-sample acknowledgments: `PYNQ_ACK_V1`.
- Board status: `PYNQ_STATUS_V1`, including gate state, integrity counters and latency summaries.
- Command acknowledgments: `type: command_ack`, preserving `command_id`.

Each connection produces `pynq_ack_<session_id>.csv` in the server's working directory. Use a simple session identifier containing only letters, digits, underscores and hyphens. Preserve the CSV alongside the Windows session records.

The `missing` counter records sequence gaps observed at arrival; late packets are counted separately and do not erase that history. `acked` counts ACK objects generated by the controller, not proof of their receipt by Windows. Latency fields use one board-local monotonic clock and measure software processing intervals; confirm electrical behavior with a scope.

## Verify Offline

No board or device connection is used by the tests:

```powershell
python -m unittest discover -s Software/PYNQ/tests -p test_perf_server.py -v
```

The public edition retains the V7 protocol and control behavior, with English operator text and three focused updates: immediate LOW on malformed JSON, SIGTERM cleanup, and a monotonic sequence watermark. Earlier R2 files in a development checkout are not required for V7 PERF.
